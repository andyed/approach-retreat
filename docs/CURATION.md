## What this is

This is a **signal testbed**, not a showcase. Each trial is a tagged demonstration of the four-class taxonomy inference task: SERP screenshot + cursor + per-AOI labels overlaid. The viewer renders the observed class alongside a continuous cursor-only deferred score.

Per-AOI `label`s are the **observed** bbox-episode class — cursor re-entry, not a model call. M5's `deferred_score` is a **prediction**, reported alongside the observed label rather than folded into it. Gaze and pupil are shown for context, not used by either signal. If you disagree with the observed label on a specific trial, that trial belongs in Group F (failure modes) and the episode heuristic needs work; if you disagree with M5's score, that's a modeling question, not a labeling bug.

## Inference: bbox-episode heuristic (canonical label) + M5 deferred score (secondary)

Two signals are computed for every organic AOI; both are reported in the trial JSON and in the viewer. The heuristic assigns the canonical `label` for every AOI kind. M5 contributes a continuous score for organic AOIs only — it does not assign the label.

### Bbox-episode heuristic (canonical, all AOIs)

Walk the cursor stream against the AOI bbox. An **episode** is an enter→exit traversal where dwell ≥ 100ms (filters drive-by crossings). Label rules — this is the observed class, `label` in the bundle:

- `CLICKED` — any episode contains a click event inside the bbox.
- `DEFERRED` — ≥2 kept episodes (cursor literally re-entered the bbox).
- `EVALUATED_REJECTED` — exactly 1 kept episode.
- `NOT_APPROACHED` — 0 kept episodes.

### M5 deferred score (secondary, organic AOIs only)

Logistic regression on the M4 ten-feature approach set, **trained against NB22 gaze-derived labels** (6,800 deferred / 3,132 eval-rejected approached non-click rows across 47 AdSERP participants, `typed` attribution, cursor-only stream, press-anchored 500 ms buffer). Trained in `attentional-foraging/scripts/export_m5_v3.py`; coefficients shipped at `scripts/models/m5_v3_cursor_bands.json`.

- **LOSO AUC:** 0.789 pooled (fold mean 0.782 ± 0.057) `[LAB, AdSERP, typed, cursor-only]` — the 2026-09-18 retrain, gated to reproduce `scripts/output/viewport_bands_cursor_only/summary.json` §4.3 to 1e-06 (diff 0). *Previously: 0.769 / p\* = 0.489 / precision 87.8 % on nine features from the 2026-05-02 `m5_final_model.json` (now `m5_final_model.legacy-2026-05-02.json`); that stream selected rows by fixation and measured gaze-to-cursor distance, so it carried part of the gaze-return label and was not the runtime measurement — the 0.769 → 0.789 drop is the removal of that term, not a regression (`attentional-foraging/docs/ablations/deferred_drop_decomposition.md`).*
- **Features:** `min_dist`, `mean_dist`, `dwell_in_proximity_ms`, `mean_approach_velocity`, `max_approach_velocity`, `direction_changes`, `frac_decreasing`, `vt_top`, `vt_mid`, `vt_bot` — the cursor terms are all geometric on cursor `pageY` relative to AOI y-center; `final_dist` and `retreat_dist` are still computed by the extractor but excluded from the model (click-buffer screen, CIKM §3.4). Viewport-band terms (`vt_top`/`vt_mid`/`vt_bot`, when present) are cumulative ms the AOI's centre spent in the top/mid/bottom third of the viewport (`edmonds-2026-vpbands-v1`).
- **Domain:** organic results only (M5's training population). Ad AOIs get no M5 score; their `label` is the heuristic's, same as organics.
- **Approached-by-M5 definition:** `min_dist < 100px` (cursor came within 100px of the AOI's y-center). More permissive than the heuristic's bbox-containment definition — M5 can score an AOI the heuristic calls NOT_APPROACHED.
- **The instrument emits a score, not a label** (2026-09-19 decision). At v2's own Youden threshold (p\* = 0.477), a predicted-DEFERRED call was right 78.1 % of the time but a predicted-REJECTED call was right only 48.5 % — worse than a coin flip's complement (from TPR 0.7276 / FPR 0.4425 on 6,800 deferred / 3,132 rejected). `m5_label` (DEFERRED/EVALUATED_REJECTED at the model's own `operating_threshold` p\* = 0.660) is a convenience view at ONE point on that curve, not the canonical output.

### Why surface both

M5's label at p\* disagrees with the observed heuristic often (69 % of the M5-scored organic AOIs in this pool). The disagreement is expected, not a bug: M5's LOSO AUC of 0.789 means a hard call at any single threshold will miss often, especially on the rejected side (see the operating-points table above). M5 sees a "deferred-like signature" (close approach + dwell + retreat); the heuristic sees "literal re-approach" (cursor physically re-entered the bbox). Group D and the per-AOI badges (`M5@p* ≠ observed` chip) surface the disagreements directly so a reviewer can decide, per case, whether the score or the observed re-entry is the more defensible read — and can pick a different threshold from the operating-points table if p\* isn't the right cut for their question.

## Regime tag

**`[CURSOR-ONLY]` algorithm running on `[LAB]` data, supervision was `[LAB, NB22 gaze-derived]`.**

Per the [LAB/WILD convention](../CLAUDE.md#role-in-the-cikm-paper-the-lab--wild-bridge), the four-class taxonomy is currently `[LAB]`-only because the canonical version is gaze-derived. M5 is the named cursor-only-bootstrap that earns `[BOTH]` *if* its agreement with the gaze-derived ground truth is high enough; M5's cursor-only LOSO AUC of 0.789 against NB22 `[LAB, AdSERP, typed, cursor-only]` (`m5_v3_cursor_bands.json`) is the deployable evidence (previously 0.769 on the fixation-selected nine-feature stream; 0.794 is the `[absolute legacy]` gaze-gated diagnostic ceiling `[AR-V2:K9]`, neither deployable). The replay viewer is the visual inspection tool for that bootstrap — every disagreement between M5 and the heuristic on a specific AOI is a candidate for human adjudication.

## Selection rubric

1. **Pass 1** (`scripts/score_trials.py` in attentional-foraging) scores every trial on cursor-only features:
   ```
   score = 0.20 * normalize(n_mousemove,    50, 400)
         + 0.25 * normalize(distinct_y_bands, 2,   8)
         + 0.25 * normalize(y_band_revisits,  0,   6)
         + 0.15 * normalize(duration_ms,   5000, 25000)
         + 0.15 * has_click
         × (1 - 0.5 * pupil_dropout_rate)
   ```
   `has_click` is 1.0 for every trial in AdSERP (protocol-required) — kept for transparency but doesn't discriminate.

2. **Pass 2** (this script) takes the top **141** with a per-participant cap, extracts organic AOI bboxes, builds replay bundles with M5 + heuristic labels, and assigns each trial to the most diagnostic group it qualifies for (priority order: E → B-DEF → B-REJ → C → D → A).
